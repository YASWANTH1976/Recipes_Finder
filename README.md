# Recipe Finder Web App

A Flask-based web application that allows users to search for recipes using the Spoonacular API, view detailed recipe information (including videos and steps), and generate shopping lists. The app is styled with Tailwind CSS for a responsive user interface.

## Features
- **Search Recipes**: Enter ingredients to find recipes using the Spoonacular API.
- **View Details**: See recipe details, including ingredients, step-by-step instructions, and a video demo (if available).
- **Generate Shopping List**: Create a shopping list based on recipe ingredients.
- **Responsive Design**: Styled with Tailwind CSS for a clean, user-friendly interface.

## Tech Stack
- **Backend**: Python, Flask
- **Frontend**: HTML, Tailwind CSS
- **Database**: SQLite (for favorites, currently disabled)
- **API**: Spoonacular API for recipe data
